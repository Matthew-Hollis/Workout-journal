# Workout Journal

A single-page workout log that runs in the browser. Sessions, exercises, progress, and weigh-ins stay in local storage on this device. Use the Backup tab to export or restore a JSON file.

Open the site at [https://matthew-hollis.github.io/Workout-journal/](https://matthew-hollis.github.io/Workout-journal/).

The manifest, service worker, icon, `start_url`, and `scope` use relative paths so the app works when GitHub Pages serves it from the `/Workout-journal/` project path. You can also serve this folder with any static file server.
